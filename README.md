Руководство пользователя

Данная игра "найди пару" является простой ,но увлекательной игрой ,рассчитанной на развитие памяти ,насмотренности и внимательности!

Главная цель этой игры найти все пары одинаковых карточек.

Интерфейс:
1. Изначально все карточки скрыты.
<img width="529" height="534" alt="image" src="https://github.com/user-attachments/assets/f28d1221-66f7-4d1d-986c-5b88343fc415" />

2. Что бы начать игру нужно нажать на любую из ячеек ,тогда раскроется содержимое с картинкой ячейки.
 <img width="533" height="534" alt="image" src="https://github.com/user-attachments/assets/b335076e-cd3e-4f53-98b1-33536b93aacd" />
 
4. Если картинки на двух ячейках совпали ,то они остаются открытыми до конца игры.
<img width="530" height="539" alt="image" src="https://github.com/user-attachments/assets/481624e5-c51b-4414-953e-5576f9e88009" />

5. Если же содержимое ячеек разное ,то они скроются через некоторое время.
