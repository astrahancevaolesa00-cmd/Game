Руководство пользователя
Данная игра "найди пару" является простой ,но увлекательной игрой ,рассчитанной на развитие памяти ,насмотренности и внимательности!
Главная цель этой игры найти все пары одинаковых карточек.
Интерфейс:
1. Изначально все карточки скрыты ,чтобы узнать содержимое некоторой ячейки,нужно нажать на неё и тогда раскроется содержимое ячейки.
2. Если картинки на двух ячейках совпали ,то они остаются открытыми до конца игры, если содержимое ячеек разное ,то карточки скрываются через несколько секунд.
3. Победа считается ,когда все ячейки на игровом поле остаются открытыми.
